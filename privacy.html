개인정보처리방침

분할점수 산출컷 예측기는 교사가 학생 성적을 브라우저 안에서 계산하도록 돕는 정적 웹앱입니다. 이 방침은 2026년 8월 13일부터 적용됩니다.

핵심 안내: 입력하거나 선택한 성적 자료는 서버로 전송되지 않으며 현재 브라우저 메모리에서만 처리됩니다. 운영자는 앱을 통해 학생 개인정보를 수집하거나 보관하지 않습니다.

1. 처리 목적과 최소처리 원칙

학급별 성적을 합산하고 예상 총점, 성취도 구간 및 분할점수를 계산하는 목적으로만 자료를 처리합니다. 계산에 불필요한 학생 이름, 연락처, 주소 등은 입력하지 마세요. 앱은 학생 이름을 요구하지 않으며 학급·번호와 점수만으로 계산할 수 있습니다.

2. 처리 항목

사용자가 직접 붙여넣거나 파일로 선택한 학급, 번호, 지필·수행평가 점수를 처리합니다. 파일명과 선택한 시트명은 화면 상태 표시에만 사용합니다. 회원가입, 쿠키, 광고 식별자, 위치정보 및 분석 도구는 사용하지 않습니다.

3. 보유기간과 파기

입력 자료는 서버나 브라우저 저장소에 저장하지 않고 현재 탭의 메모리에서만 유지됩니다. 입력칸 삭제·전체 초기화 또는 탭 닫기·새로고침 시 앱 내 자료가 제거됩니다. 사용자가 내려받은 CSV는 앱이 삭제할 수 없으므로 학교의 보안·기록관리 기준에 따라 안전하게 보관하고 목적 달성 후 삭제해야 합니다.

4. 안전성 확보조치

  • 성적 계산과 엑셀 해석은 사용자의 브라우저에서만 수행하며 외부 통신 기능을 사용하지 않습니다.
  • 콘텐츠 보안 정책으로 앱의 외부 서버 연결과 플러그인 실행을 제한합니다.
  • 허용 파일 형식과 최대 파일 크기(20MB)를 제한해 잘못된 파일 및 브라우저 과부하 위험을 줄입니다.
  • 공용 PC에서는 사용 후 전체 초기화와 창 닫기를 권고하며, 내려받은 파일은 학교가 승인한 저장소에만 보관하도록 안내합니다.

5. 정보주체의 권리와 행사 방법

운영자가 학생 자료를 수집·보관하지 않으므로 앱에 저장된 개인정보에 대한 별도 열람·정정·삭제 대상은 없습니다. 사용자는 입력칸 삭제 또는 전체 초기화로 즉시 화면의 자료를 지울 수 있습니다. 앱의 개인정보 처리에 관한 문의나 권리 행사는 아래 담당 창구로 요청할 수 있으며, 법령이 정한 범위와 기한에 따라 처리합니다. 문의에는 실제 학생 이름·점수 등 개인정보를 적지 마세요.

6. 만 14세 미만 아동의 개인정보

이 앱은 학생이 직접 사용하는 서비스가 아니라 교육 업무를 수행하는 교사용 도구입니다. 학생 식별정보의 외부 전송은 없으며, 교사는 이름 대신 학급·번호 등 필요한 최소 정보만 사용해야 합니다. 별도 외부 서비스로 자료를 옮길 때에는 학교 지침과 법적 근거를 확인하고 학생을 알아볼 수 없도록 가명처리해야 합니다.

7. 제3자 제공, 처리위탁 및 국외이전

앱은 입력 자료를 제3자에게 제공하지 않으며, 외부 AI·데이터베이스·분석 서비스에 처리를 위탁하거나 국외로 이전하지 않습니다. 문의를 위해 GitHub 링크를 직접 열 경우에는 사용자가 해당 서비스로 이동하며 GitHub의 개인정보처리방침이 적용됩니다. 문의 글에는 학생 개인정보를 포함하지 마세요.
